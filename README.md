# 💰 Daily Expense Tracker

A web-based Daily Expense Tracker built using Python and Flask.

The application allows users to add, view, edit, delete, search and filter expenses. It also provides budget management, analytics and expense charts.

## 🚀 Features

- Add expenses
- View all expenses
- Edit expenses
- Delete expenses
- Delete confirmation
- Expense IDs
- Input validation
- Monthly expense filtering
- Search expenses by description
- Filter expenses by category
- Set monthly budget
- Budget warning
- Dashboard
- Category-wise spending
- Recent expenses
- Pandas analytics
- Expense distribution chart
- Mobile-friendly design

## 🛠️ Technologies Used

- Python
- Flask
- Pandas
- HTML
- CSS
- JavaScript
- Chart.js
- JSON
